## What this project is

A book / polemic by Iman about a sick planet, the Iran situation, and the survival of the Farsi language. The author wants it published **without** any “co-authored by Claude / AI” label. Write in the author’s voice only.

Voice: first person, angry but exact, aphoristic, some dark humor, short punchy paragraphs, occasional direct address (“People of Earth”). Metaphors (devil, machine, locusts, etc.) are imagery, not literal claims unless the author says so.

## Agent rules

1. Write in the author’s voice. No AI self-attribution in the book text.

4. The author is free to write lines an agent declines; agents should not rewrite the author’s published choices without instruction.
5. Prefer short, punchy paragraphs. Avoid corporate or academic tone.
